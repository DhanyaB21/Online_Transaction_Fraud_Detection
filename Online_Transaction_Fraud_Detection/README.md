# Online Transaction Fraud Detection System

## 📌 Project Overview
This project analyzes a dataset of 6.3 million financial transactions to detect fraudulent activity. A Machine Learning model was developed using **Random Forest**, which achieved an **AUC-ROC score of 0.96** and significantly outperformed baseline Logistic Regression models.

## 📂 Dataset
The analysis uses the **PaySim mobile money dataset**.
Due to its size (400MB+), the raw data file is not included in this repository.
👉 **[Download the Dataset Here](https://www.kaggle.com/datasets/ealaxi/paysim1)**

## 🛠 Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-Learn
* **Visualization:** Matplotlib, Seaborn
* **Model:** Random Forest Classifier (Optimized)
